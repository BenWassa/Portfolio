# Brag Plan: Hermes ("The Daily") — v3

## What changed from v2, and why

Ben on v2: app felt static/small; weak opening; copy didn't land; pages not all clearly rendered;
missing features and tabs. So v3 adds a virtual camera (push-ins so the UI fills the frame), opens on
a macro of the real masthead, rewrites every caption to plain and literal, holds each page long enough
to read, and adds World, Business, Following, the weekly Voices push and the lamplight dark mode.
It runs 31s, past the 25s guideline, for that extra coverage.

- Format: vertical 1080x1920, 31.0s (past the 25s guideline for the extra coverage Ben asked for)
- Tone: default preset; quiet broadsheet, plain captions (kicker + one line), every tap on the beat grid
- Camera: one persistent phone, framed by a virtual camera (push-ins so the UI fills the frame)
