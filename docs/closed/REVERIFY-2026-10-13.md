## Findings

1. **STARK card is dead.** The `BenWassa/STARK` repo was recreated on 2026-10-13 as a new
   scaffold (initial commit 12:58Z, `package.json` version 0.0.1, no Pages site). The old PWA
   that the card describes is now **`BenWassa/stark-v1`** (last push 2026-02-19), live at
   `benwassa.github.io/stark-v1/` (200). It still throws `isDevMode is not defined` on load and
   404s `assets/stark_personhealth.png`. `repoUrl` on the card now points at the new scaffold,
   and `lastVerified: 2026-10-02` is no longer true. Not edited; see decisions.
2. **Vox copy overclaims against the repo.** `Vox_Showcase` and `Vox` `main` serve the same
   `docs/index.html`; the only difference is the data file (`*.template.csv` vs real CSVs). That
   app is a static CSV table (Spanish and Mandarin, practiced counts, status, upload/export).
   It has no `localStorage`, service worker, manifest or spaced repetition. The card says
   "Offline-First", "Local Storage", "Spaced Repetition", stack "JSON", and the modal says it
   works "fully offline with clean JSON architecture". The data is CSV and nothing is offline.
   Separately, the public `https://benwassa.github.io/Vox/` page is served from the private repo
   with the real vocabulary CSVs (it is the same app with real data). The local `../Vox`
   checkout sits on the unmerged branch `explore/language-reactor-learning-intelligence`, a
   different direction (Language Reactor import and dashboard); `main` has not moved since
   2025-09-04.
3. **Narrative version labels disagree.** The real app's landing page says V2.1.1 (matches
   `package.json`). The embedded demo's header says v4.1.4 and the template's `package.json`
   says 4.1.4. The card copy says the demo is "built from an earlier version", which is true by
   date but a viewer comparing the two labels will see the opposite.
4. **`benwassa.github.io/morpheus-dream-archive/` is blank.** It serves HTML but its JS and CSS
   404 (the build resolves assets to `/assets/...` at the site root). The real app cannot be
   linked or embedded, which is why the card correctly uses the template.
5. **Wrestle real `href`** never reaches network idle (Firestore long-poll). It is not an error.
6. **Argus card image is stale.** The image still shows the pre-redesign Home ("02 OCT 2026").
   The embedded demo now shows the redesigned Home with Roles and Library tabs.
