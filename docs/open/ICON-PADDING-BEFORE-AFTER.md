# App icon standardization — five-icon before/after review

**Portfolio issue:** [#35](https://github.com/BenWassa/Portfolio/issues/35) · **Draft PR:** [#67](https://github.com/BenWassa/Portfolio/pull/67)

This review compares the existing square app assets on [`main` at 1c8775d4](https://github.com/BenWassa/Portfolio/commit/1c8775d47bd1672a7b39ba854ac0f517824bb6b9) with their corrected versions on [PR #67 at 7c8955a9](https://github.com/BenWassa/Portfolio/commit/7c8955a908ff21cc10d93d33fc00f61997168e8f). URLs are pinned to immutable commits so the before/after views cannot silently change after a merge. These are the real PNG files rendered by GitHub, **not recreated mockups**. PR #67 remains **unmerged** pending owner review.

**Target:** 1024 × 1024 RGBA, 22.5% circular corners (±2.5 percentage points), no outer padding or baked-in shadow, at least 97% fill. Mobile views reproduce the intended 90px display width. Original branding is retained. Chef’s Journal already has the orange chef-hat icon on current `main`; this PR corrects the padding and shape of that existing icon, not a screenshot-to-icon replacement.
