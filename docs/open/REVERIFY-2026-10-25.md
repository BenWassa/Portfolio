## Method

Same as `docs/open/REVERIFY-2026-10-13.md`, applied per card:

1. HTTP status of `href` and `demoUrl` via curl.
2. README, commit messages since `lastVerified` and the deployed build read against the card's
   `desc`, `techSpecs`, `projectDescriptions` text.
3. Live URL loaded in headless Chromium at 1440px and 390px; console errors, page errors and
   4xx/5xx responses collected; screenshots looked at. Cards that have no hosted site (repo links,
   private repos) were checked against a local checkout served from the repo's own `docs/` or dev
   server instead.
4. Decision rule: copy accurate and link/demo clean, then `lastVerified` becomes 2026-10-25. Any
   wrong claim or error, then nothing is edited and the discrepancy is recorded below.

Commit data came from `gh api` and fresh clones of each repo, not the local sibling checkouts.
