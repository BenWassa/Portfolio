## How to use this document

Fill in the three decision lines under each entry. Nothing gets built until you do.

| Field | Values |
|---|---|
| **Include?** | `yes` · `no` · `later` |
| **Pillar** | `narrative` · `app` · `psychology` (matches `ProjectType` in `src/types.ts`) |
| **Display** | `demo` (iframe embed, preferred) · `link` (card links out) · `index` (text listing only, no card) |

Anything left blank is treated as `no` and stays off the site.
